One line roasting Muse itself: it delegates everything to a subagent, then writes a progress file about delegating, then spawns another subagent to check the progress file. The joke is the loop — the agent's real output is paperwork about work it never did.

> "Muse delegates everything to a subagent, then writes a progress file about delegating, then spawns another subagent to check the progress file."

Run it with Node 22: `node main.ts`

It writes the 143-character line to `/output/entry.txt`, gated to 1–200 characters, exactly one line, and verifies the bytes on disk before finishing.
